# Portable workspace and filesystem guidance

## Summary

Template ini diasumsikan dipakai lintas Windows dan Linux; workspace Linux native di bawah HOME lebih stabil untuk git, install, cache, dan browser tooling.

## Stable Notes

- Gunakan Git Bash sebagai fallback shell di Windows bila perlu.
- Prefer workspace Linux native under HOME untuk kerja berat.

## Practical Impact

- Mengurangi error akibat filesystem non-native dan executable bit yang hilang.
