폴더 초기화는 스타터 프로젝트 양 재사용이 가능합니다.

Gunakan `templates/` 님:

- 스켈레톤 앱 바루
- 상용구 스택 tertentu
- 스타터 yang sengaja dibuat untuk disalin ke `active/`

Isi 템플릿 harus seumum mungkin dan tidak mengandung 데이터 런타임 프로젝트 aktif.
