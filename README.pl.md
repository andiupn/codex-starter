## 💡 Problem: „Amnezja AI”
Modele AI są niezwykle zdolne, ale cierpią na całkowitą amnezję podczas sesji czatu. Zapominają o niestandardowych błędach Twojego projektu, powtarzając w kółko te same błędy w kodowaniu, marnując budżet API i cenny czas.

---

## ⚡ Rozwiązanie: przestrzeń robocza gromadząca mądrość

### 1. 🧠 Wbudowany system pamięci nasion
Wyposażony w `.codex-memory/`, który przechowuje zlokalizowane indeksy wiedzy. Agent AI odczytuje, zapisuje i aktualizuje swoją pamięć bezpośrednio podczas zadań związanych z kodowaniem. Jeśli raz rozwiąże błąd, zapisuje rozwiązanie i nigdy nie powtarza błędu.

### 📜 2. Archiwum badawcze wielokrotnego użytku
Ustrukturyzowany katalog archiwizacji `research/` ze skryptami narzędzi wyszukiwania (`scripts/research-find.py`). Zbuduj repozytorium zweryfikowanych interfejsów API i struktur, do których agenci mogą wysyłać zapytania w ciągu milisekund.

### 🛰️ 3. Skrypty dotyczące zdrowia i konserwacji Otonom
Wymagania wstępne są sprawdzane i weryfikowane automatycznie za pośrednictwem `./scripts/project-health.sh --auto`. Zachowaj 100% zgodności z regułami obszaru roboczego, składnią pamięci i wytycznymi dotyczącymi kodu.
