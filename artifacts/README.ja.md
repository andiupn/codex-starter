フォルダー ini untuk は、生成された dari pekerjaan アプリ/プロジェクトを出力します。

コントー:

- スクリーンショットUI
- エクスポートされたレポート
- レビューマニュアルを参照してキャプチャされた出力

Untuk ベンチマーク エージェント yang sudah punya フォルダーが `experiments/` に送信され、tetap simpan 出力ベンチマークがフォルダー eksperimen terkait に送信されます。
