hal-hal 재사용 가능한 lintas 프로젝트 aktif에 대한 폴더 초기화입니다.

Gunakan `shared/` 님:

- 공동자산
- 재사용 가능한 구성 조각
- 도우미 케실 양 티닥 라약 멘자디 프로젝트 센디리

Jika sesuatu punya 라이프사이클 sendiri sebagai 앱, taruh di `active/`, bukan di sini.
