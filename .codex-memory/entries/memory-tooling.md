# Memory helper tooling in repo

## Summary

Repo menyediakan helper ringan untuk lookup, audit, dan update memory melalui index dan entry files yang ringkas.

## Stable Notes

- Gunakan memory-find untuk lookup cepat dari index.
- Gunakan memory-upsert untuk update entry tanpa membuat duplikat topik.

## Practical Impact

- Memory system tetap murah token dan mudah dirawat.
