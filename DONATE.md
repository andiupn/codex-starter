# Donate

`codex-starter` dirancang untuk distribusi gratis atau open source. Jika Anda memonetisasi melalui donasi, pakai file ini sebagai titik awal.

## Opsi Donasi

- GitHub Sponsors
- Buy Me a Coffee
- Ko-fi
- Open Collective
- Patreon

## Checklist Setup

1. Ganti nama owner dan URL dengan milik Anda.
2. Tambahkan link donasi ke `README.md`.
3. Jika memakai GitHub Sponsors, isi `.github/FUNDING.yml`.
4. Jelaskan secara ringkas apa yang didanai: maintenance, docs, support, atau template baru.

## Template Copy

Gunakan teks singkat seperti:

> Jika template ini membantu workflow Anda, dukung pengembangannya lewat donasi.

Hindari memaksa call-to-action yang terlalu agresif. Untuk repo gratis, trust lebih penting daripada hard sell.
