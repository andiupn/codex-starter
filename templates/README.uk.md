Ініціальна папка для стартового проекту, який можна багаторазово використовувати.

Гунакан `templates/` для:

- панель скелетної програми
- шаблонний стек тертенту
- starter yang sengaja dibuat untuk disalin ke `active/`

Isi template harus seumum mungkin dan tidak mengandung data runtime project actif.
